# Metric Spaces Restart Learning Queue

Status: working queue for the analysis/topology/measure restart.

Purpose: continue the theorem-by-theorem rebuild after the Set Theory toolkit.
This file is a tactical learning queue, not active LaTeX content and not a
replacement for `chapter.yaml`.

## Operating Rule

For each theorem-like target:

1. Read the statement and every definition it depends on.
2. Explain the statement in plain language.
3. Prove it by hand before treating the LaTeX proof as owned.
4. Populate Lean or a deliberate Lean `sorry` stub in `lra-lean`.
5. Populate the LaTeX proof only after the proof is understood.
6. Keep dependencies explicit so topology, measure, and multivariable analysis
   can cite the result instead of reproving it.

Definitions are learning checkpoints.  They do not create proof obligations,
but they must be understood before later theorem-like gates are attempted.

## Restart Boundary

The Set Theory restart reached the tactical Borel endpoint:

- set operations and extensional equality;
- finite and countable families;
- closure systems and generated collections;
- set algebras and sigma-algebras;
- topologies as open-set families;
- Borel sigma-algebras generated by open sets;
- metric topology and \(\mathcal B(\mathbb R^n)\) at the vocabulary level.

Volume IV now begins the first serious application layer.  The goal is not to
collect exotic examples.  The goal is to build the reusable metric-space
toolkit needed for topology, measure theory, and multivariable analysis.

## Deliberate Non-Goals

For this restart block, do not chase:

- Borel hierarchy and descriptive set theory;
- Borel cardinality;
- exotic metric spaces unless they support a later proof;
- full general-topology replacement material;
- measure construction details before metric topology and compactness are
  stable.

The measure-theory handoff should use:

- Borel sets as generated sigma-algebras from open sets;
- continuity as preimage preservation of open and Borel sets;
- compactness and closed/bounded behavior in \(\mathbb R^n\);
- countable covers and countable limiting arguments.
